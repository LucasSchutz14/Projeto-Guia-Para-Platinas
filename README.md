Esse é meu segundo projeto depois de concluir mais uma etapa do curso Full-Stack da Rocketseat, nesse projeito criei um website que mostra os troféus e as platinas mais fáceis para jogadores de PS4 e PS5, usando o VS Code e salvando no GitHub.
Minha página contém um cabeçalho, o copro do projeto e um rodapé.
Cabeçalho: Adicionei uma faixa azul fixa no topo da página, nela contém o atalho "home" os numeros de 1 a 20 e por fim outro atalho para as "redes socias"
Corpo do Projeto: Adicionei ao corpo do projeto 20 games, todos eles listados, contendo informações como, "resumo", "tempo médio para se platinar", "raridade dos troféus", e também adicionei uma imagem que remete a cada jogo para os 20 jogos.
Rodapé: Adicionei outra faixa azul, proporcional a faixa do cabeçalho, e nela coloquei minhas redes socias, quando o leitor clicar, será redirecionado automaticamnte para minhas mídias socias, abrindo uma nova janela em seu navegador.
Usei um código específico para que todas as palavras "Resumo" mudassem de fonte e de cor de uma só vez, dando assim mais enfaze a essa palavra.
Utilei uma fonte do "Google fonts" sem direitos autorais e com uma ótima visibilidade.
Utilizei uma cor neutra para o fundo da página para nao ferir os olhos do leitor.
Por fim, adicionei um "botão" com a ajuda do "Java Script", esse botão leva o leitor para o topo da página em qualquer parte que ele estiver.
Diferente do meu primeiro projeto, percebi que usei mais o "CSS" e também o "JAVASC", isso deixou a página funcional para todo e qualquer tipo de leitor.
